Objava iz lokalnog repozitorija:
git add index.html igre.html dogadaji.html kontakt.html style.css games.js games.json
git commit -m "Azurirani kontakt, dogadjaj i filteri igara"
git push

GitHub Pages ostaje podešen na main i / (root).
Kontakt koristi mailto: poveznice, ne poslužitelj za slanje poruka.
Za lokalni pregled s instaliranim Pythonom:
python -m http.server 8000
Otvori http://localhost:8000

Igre uređuj u games.json. Kategorije i broj igrača u filterima izvode se iz podataka.
Težine su uredničke procjene, a ne službene ocjene.
